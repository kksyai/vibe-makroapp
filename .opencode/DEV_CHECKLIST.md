# 📋 Полный Checklist для безопасной разработки

Этот checklist поможет вам поддерживать безопасность при повседневной разработке.

---

## 🌅 Перед началом работы

### Проверка безопасности
- [ ] Проверить, что нет открытых критических портов (5173-5175)
  ```bash
  lsof -i -P -n | grep LISTEN | grep -E "(5173|5174|5175)"
  ```
- [ ] Убедиться, что Firewall включен
  ```bash
  /usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate
  ```
- [ ] Проверить состояние Vite процессов
  ```bash
  ps aux | grep vite | grep -v grep
  ```
- [ ] Прочитать последние изменения в проекте
  ```bash
  git log --oneline -5
  ```

### Окружение
- [ ] Убедиться, что все зависимости установлены
  ```bash
  npm install
  ```
- [ ] Проверить, что .env.local создан
- [ ] Убедиться, что работает сеть (если нужно)

---

## 💻 Во время разработки

### Безопасность команд
- [ ] Использовать только безопасные команды npm
  - ✅ `npm run dev` - локальная разработка (только localhost)
  - ❌ `npm run dev --host` - открывает доступ извне
  - ❌ `npm run dev -- --host` - открывает доступ извне
- [ ] Не запускать процессы с флагом `--host` без необходимости
- [ ] Проверять порты после запуска dev серверов
  ```bash
  ~/check_ports.sh
  ```
- [ ] Отслеживать подозрительную активность в консоли

### Разработка
- [ ] Следовать стандартам кодирования проекта
- [ ] Регулярно коммитить изменения (каждые 30-60 минут)
- [ ] Не коммитить чувствительные данные (.env, API ключи)
- [ ] Проверять работу функционала перед коммитом

## 🚨 В экстренных ситуациях

### Если обнаружена подозрительная активность
1. Немедленно остановите все процессы:
   ```bash
   pkill -f node
   pkill -f vite
   ```
2. Проверьте открытые порты:
   ```bash
   lsof -i -P -n | grep LISTEN
   ```
3. Включите Firewall (если выключен):
   ```bash
   sudo /usr/libexec/ApplicationFirewall/socketfilterfw --setglobalstate on
   ```
4. Просмотрите последние логи мониторинга

### Если dev сервер не запускается
1. Проверьте, занят ли порт:
   ```bash
   lsof -i :3000
   ```
2. Остановите процесс, занимающий порт:
   ```bash
   kill -9 <PID>
   ```
3. Попробуйте другой порт:
   ```bash
   npm run dev -- --port 3001
   ```

### Если Git hook блокирует коммит
1. Проверьте, какие порты открыты:
   ```bash
   lsof -i -P -n | grep LISTEN
   ```
2. Остановите критические процессы:
   ```bash
   pkill -f vite
   ```
3. Попробуйте снова
